# Фактический статус EduPath ML 0.2.0

## Сохранённые данные и ML

SQLite, обученная Logistic SGD, reports/experiment.json и reports/model_metrics.csv не изменены. Accuracy 0,7121, F1 0,7981, ROC-AUC 0,7276, Log Loss 0,5653. Train: 3330 учеников; test: 833 ученика и 59 642 ответа. Обучение и большие эксперименты при изменении UI не запускались.

Отбор остаётся прежним: до четырёх слабых тем с материалами при прогнозе <0,50 и минимум трёх ответах, затем необходимая подготовка. Библиотека содержит 23 записи, граф — пять рёбер; покрытие 125 669 ответов (44,39%) и 3119 учеников. Прогнозы и истории разных ID не объединяются. Маршруты: 79021 — 292→290→2_37_70→39→299; 75169 — 292→9_12; 78970 — 16_17→290→17→294.

## Исправления и учебный интерфейс

Пользователь проверил предыдущую версию в реальном браузере и сообщил KeyError двух полей. Текущий Service их уже возвращал, но UI не проверял контракт и кэшировал данные. Конкретный процесс в Ubuntu здесь недоступен; устаревший API — вероятная причина, а не доказанный факт. Исправлена граница обмена: контракт 2 проверяется сервером и клиентом, старый/неполный ответ отклоняется с инструкцией перезапуска. Health сообщает app_version=0.2.0 и trajectory_contract_version=2. UI получает профиль и план одним ответом, без кэширования данных ученика.

Три раздела: «Профиль ученика», «Анализ знаний», «План обучения». Показатели профиля расположены в адаптивной сетке; анализ — в таблицах и подробностях. У плана есть пронумерованные шаги, цели, теория, разобранные примеры, фиксированная практика с решениями, ссылки и переходы. Все 23 записи дополнены при чтении, без изменения БД. Локальные отметки существуют только в текущей сессии и не оценивают знания. Метрики ML убраны из основной навигации, сохранены в файлах и /model/info.

## Проверено после исправления

23 связанных unittest прошли: прежние 17 и шесть новых тестов контракта, отдельных записей и математических ответов. DataTests не запускались. FastAPI ASGI проверил контракт 2, каталог уроков, три маршрута и 404/422. Связка FastAPI ASGI → JSON → HTTP-клиент → Streamlit AppTest открыла три раздела и все шаги 79021/75169/78970, проверила переходы и локальные отметки. Старый ответ без detected_difficulties/material_count воспроизведён и отклонён без исключения интерфейса. Отчёты: reports/asgi_integration.json и reports/streamlit_asgi_integration.json.

ASGI использует прямое исполнение синхронных обработчиков вместо пула потоков. HTTP-транспорт в AppTest подменён вызовом ASGI; это реальные сериализованные ответы приложения, но без сети. Сокеты запрещены. Браузер после этих изменений не доступен; адаптивные стили реализованы, визуальный результат не подтверждён. Прежние отчёты сохранены в reports/ui_revision_before/.
