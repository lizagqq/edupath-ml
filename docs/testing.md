# Проверки интерфейса 0.2.0 и контракта траектории 2

Выполнены 23 связанных unittest: RecommendationTests, ServiceTests, APITests, PresentationTests и шесть LearningContractTests. Проверены прежние правила выбора и порядка тем, данные профиля, раздельные ID, ошибки API, новый контракт и фиксированные задания. DataTests и обучение даже на демонстрационных данных не запускались.

```bash
PYTHONPATH=tests .venv/bin/python -m unittest test_core.RecommendationTests test_core.ServiceTests test_api.APITests test_ui_presentation.PresentationTests test_learning_contract.LearningContractTests -v
```

Новые проверки воспроизводят отсутствие `detected_difficulties` и `material_count`, неверную версию, неполный урок, неверный тип решения и нарушение зависимости. Клиент отклоняет ответ до отображения с понятной ошибкой. Все 23 ID имеют статическую цель, теорию, пример и 1–2 задания; ответы пересчитаны независимо с Fraction, формулами площадей, преобразованиями координат и арифметикой. Отдельно проверены естественное склонение количеств и сохранение отдельных одноимённых записей.

`reports/asgi_integration.json`: настоящий FastAPI, контракт 2, 149 ID профиля, 23 дополненных материала, маршруты 79021/75169/78970 и 404/422. `reports/streamlit_asgi_integration.json`: FastAPI ASGI → сериализованный JSON → проверка HTTP-клиентом → настоящий Streamlit AppTest. Открыты три раздела и все шаги трёх учеников; проверены переходы, раздельные записи, отметки и воспроизведение старого неполного ответа. Прямая подмена Service вместо API для этой основной проверки не используется.

```bash
.venv/bin/python scripts/smoke_asgi.py
.venv/bin/python scripts/smoke_streamlit.py --asgi
```

В ASGI-проверках стандартный пул потоков заменён прямым исполнением синхронного обработчика. requests.get заменён транспортом внутри процесса, возвращающим JSON настоящего FastAPI. Это не сетевой HTTP и не проверка стандартного worker-пула. AppTest проверяет элементы и состояние, но не пиксели и размеры окна. Сокеты запрещены, браузер не доступен; адаптивность нужно осмотреть в Ubuntu по docs/wsl_runbook.md.

Исторические отчёты 17/17 и прежнего AppTest сохранены в reports/ui_revision_before/. Прежний полный набор 21/21 не обозначается как текущий полный прогон. Нынешние 23 теста — связанный набор после изменения UI; общий набор с DataTests не запускался.

Контрольные суммы БД, модели, эксперимента, CSV метрик и курсовой сохранены до изменения и проверяются в reports/ui_revision_check.json. Метрики поиска 9/9 из прежнего отчёта не пересчитывались и не представляются оценкой расширенного учебного содержания. ML-метрики и показатели покрытия не пересчитывались.
