# Постановка задачи и критерии

Тема: «Разработка программного комплекса для оценки уровня знаний и формирования индивидуальных траекторий обучения». Объект — история математических ответов в LMS; предмет — причинный прогноз следующего ответа и порядок повторения тем.

Вход: исправленный collapsed CSV ASSISTments Skill Builder 2009–2010 с `user_id`, `skill_id`, `order_id`, `correct` и метаданными; дополнительный синтетический режим используется только для технической проверки. Выход: очищенные данные, EDA, профиль ученика с наблюдаемой точностью и количеством ответов, вероятность следующего правильного ответа по навыку, маршрут с причинами и ссылками, метрики offline-проверки.

Функции: импорт и контроль схемы; очистка; причинные признаки; групповое разделение; обучение и сравнение с baseline; SQLite; поиск материала; граф prerequisite; API и русскоязычный интерфейс. Не входят полноценная LMS, регистрация, автоматическое назначение реальных заданий и генеративная LLM.

Критерии приёмки: отсутствие признаков текущего/будущего ответа и пересечения ID учеников; реальные Accuracy/F1/ROC-AUC/Log Loss/Brier на holdout; три разных маршрута с объяснениями; обработка ошибочных API-запросов; тесты критических функций; явное описание ограничений. Педагогический эффект маршрутов потребует отдельного исследования с пользователями.
