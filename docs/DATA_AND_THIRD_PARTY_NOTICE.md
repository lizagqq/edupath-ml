# Данные и сторонние материалы

Состав публикации подготовлен 17.11.2026. Никакая общая лицензия на код проекта в ходе подготовки автоматически не назначалась. Приватный GitHub-репозиторий не меняет прав владельцев сторонних материалов.

## ASSISTments

CSV 2009–2010 и его производные таблицы ответов/SQLite оставлены локально. Подробности источника, известных условий и восстановления БД без обучения — [data/README.md](../data/README.md). Предупреждение об идентифицирующей информации взято с официальной страницы. Подробный документ условий не удалось автоматически прочитать; утверждения о безусловном праве повторного распространения файла нет.

В репозиторий предназначены параметры обученной логистической модели и агрегированные результаты: они не содержат исходные строки ответов, имена, тексты ученических ответов или таблицу истории учеников. Учебные примеры в документации используют псевдонимизированные ID; их не следует считать ФИО реальных людей. Развёрнутый JSON профилей docs/figures/document_evidence.json и исходные данные исключены.

## OpenStax

Короткие русские пояснения, фиксированные задачи и решения подготовлены в коде проекта; источник для дополнительного чтения указан в каждой карточке. Полные тексты учебников не копируются в репозиторий. Ссылки на страницы OpenStax не передают права на весь учебник и его иллюстрации. Четыре записи Circle Graph используют одинаковое вводное чтение; это не четыре разных курса.

## Методические файлы и курсовая

PDF методички, сборник лабораторных, исходный ZIP задания, Word-документы, архив прежних редакций и внутренние инструкции оставлены локально. Они не нужны для запуска и могут содержать сторонние материалы или личные реквизиты. В публикационную копию включается техническая Markdown-документация и собственные схемы. Наличие настоящих скриншотов интерфейса не подтверждено: reports/screenshots содержит только .gitkeep; макет ui_structure.png не выдаётся за скриншот.

## Размеры

Локальные CSV — 64 412 812 байт и 13 930 525 байт, SQLite — 14 389 248 байт. Они меньше жёсткого лимита GitHub в 100 MiB на файл, но исходный CSV превышает порог предупреждения 50 MiB. Исключение обусловлено также составом данных и неопределённостью прав на повторную публикацию; Git LFS эту задачу не решает. Официальная справка: https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github.
