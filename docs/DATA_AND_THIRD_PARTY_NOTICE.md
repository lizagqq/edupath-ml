

Локальные CSV — 64 412 812 байт и 13 930 525 байт, SQLite — 14 389 248 байт. Они меньше жёсткого лимита GitHub в 100 MiB на файл, но исходный CSV превышает порог предупреждения 50 MiB. Исключение обусловлено также составом данных и неопределённостью прав на повторную публикацию; Git LFS эту задачу не решает. Официальная справка: https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github.
