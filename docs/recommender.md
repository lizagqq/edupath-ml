# Диагностика, база знаний и индивидуальная траектория

## Основание выбора

Профиль содержит отдельную запись для каждого из 149 `skill_id` ASSISTments. Для прогноза следующего ответа используется уже обученная Logistic SGD; модель и её метрики при переработке рекомендаций не изменялись. После накопленной истории ученика навык считается **выявленным затруднением**, если по нему есть минимум три ответа и прогноз правильного следующ ответа ниже 0,50. Это порог интерфейса и отбора, а не доказательство неосвоения. При 3–9 ответах вывод прямо помечается как **предварительный сигнал**; при 1–2 ответах навык не попадает в рейтинг затруднений.

`scripts/analyze_skill_demand.py` воспроизводит анализ всех профилей по сохранённой модели без обучения и записывает `reports/skill_demand.json`. Число учеников с затруднениями при пороге выше: перевод дробей/десятичных/процентов (ID 47) — 196, сложение и вычитание целых (277) — 195, неизвестное название ID 76 — 176, нахождение процентов (77) — 173, методы подсчёта (16_17) — 142, показатель на единицу (81) — 142, один из ID круговой диаграммы (2_37_48_77) — 125, диаграмма «стебель и листья» (9_12) — 115. Ученик 79021 имеет низкие прогнозы для поворотов (292), поверхности цилиндра (299), отражения (290) и двух отдельных ID круговой диаграммы. Это анализ потребности в материалах, не оценка эффекта обучения.

## Библиотека и связи

Библиотека расширена с 9 до **23 записей по реальным ID**. Четыре ID с исходной меткой *Circle Graph* (`2_37_70`, `2_37_48_77`, `2_48_79`, `2_70`) хранятся раздельно; их прогнозы и числа ответов не объединяются. Пока источник данных не раскрывает педагогическое различие этих ID, им привязано одно и то же вводное чтение по круговым диаграммам. В коротком основном маршруте показывается один ID с этим названием, остальные остаются в диагностике и могут попасть в дополнительное закрепление. Для ID 76 в исходных метаданных нет названия; материал не выдуман.

Новые объяснения и примеры составлены для поворотов, отражения, площади круга и поверхности цилиндра, круговых диаграмм, методов подсчёта, вероятности двух событий, диаграммы «стебель и листья», площади неправильной фигуры, целых чисел и показателя на единицу. К ним добавлены короткие оригинальные задания для самостоятельной сверки ответа; ответы **не оцениваются и не сохраняются**. При миграции `scripts/sync_knowledge_base.py` сверяет каждый новый ID с точной исходной меткой в SQLite и меняет только таблицы `materials` и `prerequisites`. В `reports/knowledge_base_sync.json` сохранены SHA-256 неизменённых модели и отчёта метрик.

Материалы опираются на конкретные страницы OpenStax: [повороты и отражения](https://openstax.org/books/contemporary-mathematics/pages/10-5-tessellations), [площадь поверхности цилиндра](https://openstax.org/books/prealgebra-2e/pages/9-6-solve-geometry-applications-volume-and-surface-area), [площадь круга и неправильных фигур](https://openstax.org/books/prealgebra-2e/pages/9-5-solve-geometry-applications-circles-and-irregular-figures), [круговые диаграммы](https://openstax.org/books/introductory-statistics-2e/pages/1-2-data-sampling-and-variation-in-data-and-sampling), [стебель и листья](https://openstax.org/books/introductory-statistics-2e/pages/2-1-stem-and-leaf-graphs-stemplots-line-graphs-and-bar-graphs), [методы подсчёта](https://openstax.org/books/contemporary-mathematics/pages/7-1-the-multiplication-rule-for-counting), [вероятность совместных событий](https://openstax.org/books/contemporary-mathematics/pages/7-9-conditional-probability-and-the-multiplication-rule), [целые числа](https://openstax.org/books/elementary-algebra-2e/pages/1-3-add-and-subtract-integers), [показатель на единицу](https://openstax.org/books/prealgebra-2e/pages/5-6-ratios-and-rate).

К четырём прежним связям `67→61`, `47→77`, `47→70`, `311→312` добавлена одна связь `39→299`: площадь круга требуется для формулы полной поверхности цилиндра. Это педагогический вывод из [формулы и подготовительного задания OpenStax](https://openstax.org/books/prealgebra-2e/pages/9-6-solve-geometry-applications-volume-and-surface-area), а не утверждённая онтология. Для других новых тем связи не добавлялись без обоснования. Пять рёбер образуют ацикличный граф. 23 записи материалов охватывают 125 669 из 283 105 пригодных ответов (44,39%) и встречаются хотя бы раз у 3119 учеников; наличие материала не означает автоматического включения в маршрут.

## Алгоритм короткого маршрута

1. Составить упорядоченный список выявленных затруднений по прогнозу; сохранить каждый `skill_id` отдельно.
2. Для основного маршрута выбрать не более **четырёх** слабых навыков с материалом. При одинаковой исходной метке не показывать две одинаковые концептуальные карточки подряд; второй ID остаётся отдельной диагностической записью.
3. Добавить необходимые предварительные темы из графа, если по ним менее трёх ответов или их прогноз ниже 0,70. Предварительная тема с умеренным риском явно объясняется зависимостью. Подготовленные, но не выбранные слабые темы — не более трёх — показать как **дополнительное закрепление**.
4. Все слабые навыки без материала показать в отдельном разделе «Обнаружены затруднения, материал пока не подготовлен». Если для выявленных затруднений материалов нет, не выдавать общий каталог за маршрут.
5. Внутри выбранного множества использовать прежний балл `100×(1−p) + 15` при менее трёх ответах `+ 8` при слабой предварительной теме. При выборе следующего шага соблюдать порядок графа. Балл скрыт в техническом раскрывающемся блоке; это не процент освоения.

Фактические маршруты после обновления: `79021` — пять шагов (повороты, отражение, один ID круговой диаграммы, площадь круга как подготовка, поверхность цилиндра); `75169` — два шага (повороты, «стебель и листья»); `78970` — четыре шага (методы подсчёта, отражение, вероятность двух событий, площадь неправильной фигуры). Для 79021 ID 76 и ещё шесть слабых навыков показаны отдельно без материалов. Подробные отдельные ID и маршруты записаны в `reports/system_evaluation.json` и `reports/streamlit_apptest_local.json`.

## Ограничения повторной проверки

Добавленные задания позволяют ученику самому сверить ответ, но система не фиксирует новую попытку и не обновляет знания по её результату. Для полноценного повторного теста понадобятся проверенный банк заданий по навыкам, правила оценки, сохранение ответов и времени, обновление профиля и отдельная проверка педагогической пригодности. Ориентир для технического прототипа с ручной проверкой небольшого банка — **3–5 рабочих дней разработки**; экспертная подготовка заданий и исследование эффекта в эту оценку не входят. Текущая версия не делает вывод о пользе маршрута для обучения.

## Учебное представление плана — 0.2.0

Правила выбора, пороги и пять рёбер сохранены. Пользователь видит последовательность пронумерованных тем, а материал выбранного шага раскрывается как урок: цель, теория, разобранный пример, 1–2 фиксированных задания с решениями и источник. Дополнения хранятся в src/retrieval/lessons.py и добавляются при чтении; SQLite и коэффициенты модели не менялись. Четыре Circle Graph по-прежнему отдельные ID с одинаковым вводным материалом.

Отметка «Я разобрал(а) этот шаг» — состояние текущей сессии по ученику и ID. Она не оценивает успешность и не меняет маршрут или вероятность. Новых фактических ответов приложение не собирает. Подробности контракта и проверки — docs/ui_revision.md.
