# Технические решения

1. **Задача прогноза.** Оценивается вероятность правильного *следующего ответа* на навык, не абсолютный «уровень владения». Счётчики обновляются после прогнозируемой строки.
2. **Источник.** Пользователь предоставил `skill_builder_data_corrected_collapsed.csv`; имя и Windows-метаданные загрузки совпадают с ID исправленной collapsed-выгрузки на официальной странице. Независимого издательского SHA-256 нет; локальный хеш записан для воспроизводимости.
3. **Очистка.** 63 755 строк без навыка исключены. 8 515 строк с ID навыка, но без названия, сохранены с названием-ID. Пять битых UTF-8 байтов находятся в неиспользуемом `answer_text`, при чтении заменяются. Повторы `(user_id,problem_id)` не удаляются, поскольку `order_id` различен и может отражать новые попытки.
4. **Валидация.** Holdout по `user_id` (3330/833 учеников) предотвращает пересечение. История test-ученика доступна только до прогнозируемого события. Все 283 105 пригодных ответов используются без выборки.
5. **Модель и ресурсы.** В среде 3,8 ГБ ОЗУ и нет scikit-learn; Logistic SGD на стандартной библиотеке обновляет только активный коэффициент навыка. Обучение и JSON-артефакт реально проверены. RandomForest и MLflow остаются непроверенными зависимостями.
6. **Граф и материалы.** 23 записи по ID сопоставлены с реальными метаданными и OpenStax. Пять ручных рёбер проверяются на ацикличность; новая связь 39→299 обоснована площадью круговых оснований цилиндра. Экспертной валидации графа нет.
7. **Интерфейс.** Основной UI — Streamlit с четырьмя разделами. AppTest проверяет его с локальным Service; FastAPI ASGI проверяется с прямым выполнением обработчиков из-за ограничений пула потоков. Сетевой и визуальный запуск новой версии остаётся внешней проверкой.

8. **Проверка интеграции.** FastAPI и Streamlit установлены в .venv. Нельзя выдавать AppTest и ASGI с подменой пула потоков за реальный HTTP. Для обычной Ubuntu сохранены отдельные smoke-сценарии.
9. **Согласование диагностики и маршрута.** Основные темы выбираются только среди наблюдавшихся навыков с прогнозом <0,50 и минимум тремя ответами. Не более четырёх разных исходных названий входят в основной маршрут; разные ID сохраняются в диагностике. Предварительные темы добавляются по графу при прогнозе <0,70 или нехватке истории. Остальные слабые навыки с материалами могут стать закреплением, без материалов показываются отдельно.

## 2026-11-10: учебный сценарий и защита контракта

Данные ученика читаются одним некэшируемым запросом траектории, который уже включает профиль. Service и клиент проверяют общий контракт версии 2, включая вложенные уроки. При старом ответе нет восстановления отсутствующих полей значениями по умолчанию: требуется согласованная версия сервера и интерфейса. Health сообщает версии для диагностики устаревшего процесса.

Учебное содержание расширяется read-only слоем над 23 материалами без миграции SQLite и переобучения. План показывается как последовательность с одним открытым уроком, чтобы сохранить обозримость. Прогресс — только пользовательские отметки session_state по ученику и навыку; он не интерпретируется как оценка знаний. Метрики доступны отдельно от учебной навигации. Интеграция проверяется JSON настоящего FastAPI в Streamlit AppTest, а визуальная раскладка — отдельным ручным сценарием в браузере.
